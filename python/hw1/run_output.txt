===== q06_find_bug.py =====
题目代码：
  if __name__ == '__main__':
      list = list(range(1000))
      for idx in range(len(list)):
          if list[idx] % 2 == 1:
              list.pop(idx)

bug 在哪：
  1. range(len(list)) 只在循环开始时算一次长度，随后 list.pop 让列表变短，
     索引仍然走到原来的上限，于是 list[idx] 越界，抛出 IndexError。
  2. 删除元素后后面的元素整体前移一位，下一次循环 idx 加 1 会跳过紧邻的那个元素，
     即使不报错也会漏删奇数。
  3. 列表是可变对象，循环里修改它的长度，下标与元素的一一对应关系就被破坏，
     而 range 生成的下标序列是固定的，不跟着变。

运行原代码的结果: IndexError: list index out of range

倒序删除: 剩余 500 个元素，全是偶数: True，前 5 个: [0, 2, 4, 6, 8]
列表推导式: 剩余 500 个元素，全是偶数: True，前 5 个: [0, 2, 4, 6, 8]
while 修正下标: 剩余 500 个元素，全是偶数: True，前 5 个: [0, 2, 4, 6, 8]
切片取偶数位: 剩余 500 个元素，全是偶数: True，前 5 个: [0, 2, 4, 6, 8]
